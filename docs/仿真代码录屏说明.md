# 衣循仿真代码录屏说明

## 推荐录屏顺序

在 VS Code 中打开 `yixun-robot` 仓库文件夹，只展示以下四个入口文件：

1. `run_simulation_suite.py`：统一启动器。
2. `simulate_chassis.py`：底盘综合仿真。
3. `create_arm_hanging_3d_sim.py`：机械臂挂衣仿真。
4. `create_wardrobe_storage_sim.py`：旋转衣柜收纳仿真。

`chassis` 文件夹中的算法模块可在讲解底盘技术路线时快速点开：

- `slam.py`：占用栅格 SLAM。
- `path_planner.py`：融合地形代价的 A*。
- `obstacle_avoidance.py`：DWA 动态避障。
- `phototropism.py`：趋光位置优化。
- `voice_nav.py`：语音目标解析。

## VS Code 终端命令

先展示模块目录：

```powershell
python run_simulation_suite.py --list
```

分别运行三项仿真：

```powershell
python run_simulation_suite.py chassis
python run_simulation_suite.py arm
python run_simulation_suite.py wardrobe
```

一次运行全部模块：

```powershell
python run_simulation_suite.py all
```

## 录屏建议

- 录制分辨率使用 `1920 × 1080`。
- VS Code 字号调整至 `18-20`，隐藏无关插件和个人账号信息。
- 每个模块先展示约 5 秒核心代码，再运行命令并打开生成的 MP4。
- 总时长控制在 `45-60 秒`。
- 不要展示学校名称、校徽、个人文件路径或通知信息。
