## 二、核心算法公式（PPT 展示用）

### 1. A* 路径规划

```
f(n) = g(n) + h(n)
g(n) = Σ (地形代价 × 栅格距离)
h(n) = √[(nx-gx)² + (ny-gy)²]    (欧几里得启发式)
```

门槛、地毯等地形通过 `TERRAIN_COST` 体现履带越障难度差异。

### 2. 占用栅格 SLAM

```
L(m|z) = clip(L(m|z⁻¹) + ΔL, L_min, L_max)
P(occ) = 1 - 1/(1 + exp(L))
```

激光射线沿 Bresenham 算法更新自由/占用栅格。

### 3. 动态窗口法 DWA

```
G(v,ω) = α·heading + β·dist + γ·velocity - δ·obstacle_cost
```

在速度空间采样，预测轨迹并避开动态障碍。

### 4. 趋光追踪

```
I(x,y,t) = sin(elevation) · facing(azimuth) · shadow(x)
```

在阳台可行域内梯度搜索 `(x*, y*) = argmax I(x,y)`。

## 三、快速运行

```bash
cd yixun-robot
pip install -r requirements.txt
python run_all_demo.py
```

或分步运行：

```bash
python run_simulation_suite.py --list   # 查看全部仿真模块
python simulate_chassis.py              # 底盘仿真 → output/chassis_demo.mp4
```

## 五、项目结构

```
yixun-robot/
├── chassis/                 # 底盘算法包
│   ├── robot.py             # 履带运动学
│   ├── terrain.py           # 多地形地图
│   ├── slam.py              # SLAM
│   ├── path_planner.py      # A*
│   ├── obstacle_avoidance.py# DWA
│   ├── phototropism.py      # 趋光
│   └── voice_nav.py         # 语音导航
├── simulate_chassis.py      # 底盘仿真主程序
├── create_arm_hanging_3d_sim.py  # 机械臂三维挂载仿真
├── run_simulation_suite.py  # 三类仿真统一启动器
├── run_all_demo.py          # 一键运行可复现演示
├── tools/                   # 报告与图表构建脚本（归档）
├── docs/                    # 设计报告、开发日志、汇报 PPT、本文档
├── assets/                  # 演示动图、插图、海报、数据、App 原型
└── requirements.txt
```
